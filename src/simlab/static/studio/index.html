模型接入

为不同 API 服务和 AI 模型分别保存配置，随时切换。正在执行的调整仍使用发送时的模型。

填写 API 地址和服务商提供的模型标识，不是聊天网页地址。支持上述两种兼容接口。配置会保存在本机；密钥仅保存在本次服务进程中，重启后需重新填写。提示词、当前模型与指标会发送至所选服务。

DeepSeek 官方接口的参数调整使用非思考模式，以便及时返回修改方案。方案仍需经过参数校验和仿真评估。
