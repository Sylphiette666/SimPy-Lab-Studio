## 二、关键行为与使用边界

### 草稿恢复

- 草稿写入 `experiments/<实验 ID>/drafts.json`，最后打开的实验和备份选项写入 `experiments/workspace.json`。
- 浏览器存储用于即时缓存及旧草稿迁移；同步成功后，清理浏览器缓存或改变本机服务端口仍可恢复。
- 保存失败会保留待同步内容、显示提示并自动重试。强制退出前尚未同步的输入仍可能丢失。
- 多窗口更新使用修订号检查，发生冲突时保留冲突副本，可从实验管理导出；不会直接覆盖另一窗口的新草稿。
- 草稿恢复不等于模型已应用，仍需点击“应用修改并预览”。中断的仿真需要重新运行。

### API Key 与模型接入

- 关闭设置窗口后重新打开，会回填当前运行中已配置的密钥。
- 退出整个软件后要继续恢复密钥，需勾选“在本机加密保存密钥”并保存，由当前 Windows 账户保护。
- 回填值默认遮挡，密钥不写入浏览器持久草稿或实验导出；迟到的读取响应不会覆盖用户新输入。
- DeepSeek 模板使用 `https://api.deepseek.com/v1` 和 Chat Completions；模型可手动修改，服务端实际可用性以账户和接口为准。实现细节及此前核对记录见[模型接入说明](model-settings-update.md)。
- 连接测试使用正在编辑的配置，不自动保存或切换配置；点击后会发送简短请求，可能产生少量费用。

### 表格导入与参数检查

- 支持 UTF-8／GB18030 CSV 和单工作表 XLSX；上限 1 MB、500 条数据行、40 列，不支持旧 `.xls`。
- 不执行公式、宏或外部链接；公式应先转换为数值。
- 按设备／容器类型及从 1 开始的序号更新现有对象；空白参数保留原值，可用率按百分数填写。
- 先映射列、查看修改差异，再确认写入草稿。解析或整体校验失败时不会部分应用。
- 联动检查预热时长小于仿真时长、可用率不足 100% 时维修时间大于 0 等约束。

### 批量计算与统计诊断

- 每批最多扫描 3 个参数、16 个组合；最多两个运行或排队的批量任务，顺序计算。
- 各组合沿用相同实验设置及重复编号派生的种子；整批预计事件量上限为 800 万。
- 取消在当前一次重复完成后生效；已完成组合保留，重启不会自动重跑中断任务。
- “采用此方案”通过原有版本校验和预览流程执行；基准版本变化后禁止覆盖当前模型。
- 诊断从完整重复实验计算 t 区间，设备状态采用事件积分结果，排除预热；不根据动画采样帧推断统计结果。
- 配对比较要求时长、预热、基础种子和置信水平一致。单次结果不计算区间，零观测方差不代表确定性，多指标检验尚未校正。
- 实测校准在有限参数网格内按相对误差均方根排序，不保证全局最优；建议使用独立生产数据验证。

### 备份与恢复

- 自动备份默认关闭；开启后生成备份，软件运行期间检查距上次备份是否满 24 小时，保留最近 7 份。
- 备份包含实验、版本、对话、结果、草稿及批量任务，排除 API 配置和密钥。
- 支持完整备份 ZIP 及原有实验导出 ZIP，先预览再确认恢复；使用新实验 ID，不覆盖原实验。
- 恢复上传上限 25 MB，展开上限 100 MB、100 个实验。软件关闭期间不执行自动备份。

## 三、回归过程中修正的问题

1. 完整读取工作区保存请求的响应，避免浏览器长时间认为请求仍未结束。
2. 草稿请求中途断开时保留待同步数据，无需用户再次编辑即可重试；错误提示持续到同步成功。
3. 模型重新渲染后重新校验关联字段，避免沿用过期的字段有效性状态。
4. 批量任务完成后同步更新历史列表中的中文状态。
5. 工作区会恢复上次实验后，调整旧浏览器测试的准备步骤，明确创建独立实验再验证。
6. 将批量任务结果纳入备份恢复，补充任务标识重映射及中断状态处理。
