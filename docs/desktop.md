# SimPy Lab Studio 桌面版使用说明

SimPy Lab Studio 1.0.0 面向 Windows 10/11 x64。它将制造仿真、模型编辑、AI 辅助调整和统计评价整合进一个桌面窗口。

## 安装和启动

推荐下载发布页中的 `SimPy-Lab-Studio-Setup-1.0.0.exe`，按中文向导安装。它会创建开始菜单入口、可选桌面快捷方式和卸载入口，并在缺少 WebView2 时联网安装该组件。详见 [安装与分享说明](installer.md)。

便携版仍可下载 Windows ZIP，解压得到“SimPy Lab Studio”文件夹。该文件夹只包含 `SimPy Lab Studio.exe`。两种版本都不需要 Python、命令行或手动启动本地服务。

EXE 内置软件图标、界面资源、Python 运行库和应用依赖。首次启动时会将运行库临时解压到系统临时目录，因此比后续操作慢。界面使用 Windows WebView2 组件，显示在软件自己的窗口里，没有浏览器地址栏或标签页。若系统缺少组件，请从 [Microsoft WebView2 官方页面](https://developer.microsoft.com/microsoft-edge/webview2/)安装 Runtime 后重新打开。

软件会选择一个可用的本机端口运行独立后台服务；通常复用上次端口，被占用时自动选择其他端口。重复双击会激活已经打开的窗口。关闭软件会停止它自己的服务，不影响另行运行的浏览器版。

## 操作流程

1. **编辑初始模型。** 左侧选择论文或自定义模式，设置设备、缓冲区、班次、时长和重复次数，点击应用。
2. **观察仿真。** 运行预览，再播放、暂停、变速或拖动进度条。颜色表示加工、等待、阻塞、故障和计划停机。
3. **连接 AI 模型。** 点击顶部“模型接入”，新建配置，填写名称、API Base URL、模型名称、接口格式和 API Key。可以使用 OpenAI、DeepSeek 快捷模板后继续编辑。
4. **随时切换。** 在助手的“当前 AI 模型”下拉框选择配置；下一次提示词使用新配置。已发送的请求继续使用发送时的连接，每次历史回复和版本保留实际模型来源。
5. **自然语言调整。** 输入期望目标或精确修改。应用校验返回的参数，通过后创建新版本并从零重新仿真。
6. **评估、恢复和导出。** 完整评估按该版本时长与重复次数运行。选定方案后点击导出实验，在 Windows 保存对话框中选择 ZIP 路径。导出模型 JSON 和导入 JSON 也使用系统文件对话框。

“帮助 → 使用说明”可以在软件内查看简要操作；“关于软件”显示版本和数据路径；“开源组件许可”显示随软件内置的许可信息。

## 配置与数据保存

用户数据位于：

```text
%LOCALAPPDATA%\SimPy Lab Studio\
├── experiments\         实验、版本与已完成的仿真结果
│   └── ai_profiles.json  模型连接列表，不含密钥
├── webview\             界面缓存与本地选择状态
├── runtime.json         上次使用的本机端口与运行状态
├── desktop.log          桌面启动日志
└── server.log           后台服务日志
```

使用“文件 → 打开实验数据目录”进入。安装版更新时先关闭旧版，再运行新版安装程序；便携版可直接替换 EXE。卸载安装版会保留实验数据。备份实验时可导出 ZIP；备份整个本机工作空间时请先关闭软件，再复制数据目录。浏览器版的数据仍在它原来的输出目录，两者不会互相覆盖；可以用模型 JSON 将初始配置导入桌面版。

API 密钥仅保留在当前进程内存中；关闭软件后重新填写。修改配置时留空会保留相同 API 地址的现有密钥，更换地址须重新填写。可以勾选移除密钥。OpenAI 网页登录和 ChatGPT 网页地址不能代替 API 密钥与 API Base URL。

关闭窗口会结束后台任务。已经写入的模型版本与结果保留；尚未完成的任务会在下次打开时显示被中断，请重新运行。

## 模型和结果的含义

预览使用实际 SimPy 模型生成采样状态，动画播放速度不会改变计算结果。预览默认最多覆盖“预热期加一天”，完整统计评估才使用整个实验时间。单轮预览不能代替重复实验的均值和置信区间。

论文模式保持案例一设备顺序与缓冲容量约束，自定义模式允许额外探索。每次调整产生独立版本，不是对正在加工的工件原地修改参数续跑。软件目前不包含写实三维场景；真实工厂应用需要测量数据与模型校准。完整口径见 [Studio 说明](studio.md) 与 [案例一实现](paper_case_a.md)。

## 开发验证和打包

`tools/build_desktop.py` 生成图标和内置许可文件，然后调用 `desktop.spec` 进行 PyInstaller 单文件构建。发行版不需要构建工具。

自动化自检可用以下命令验证内置静态资源、后台服务启动、实际短时仿真和退出清理，不调用外部 LLM：

```powershell
& '.\dist\SimPy Lab Studio.exe' --self-test '.\outputs\desktop-self-test.json' --data-dir '.\outputs\desktop-self-test-data'
```

浏览器测试和模型配置测试使用独立测试服务，详见 [开发验证](studio.md#开发验证)。桌面界面验证应另外检查 EXE 窗口、文件保存对话框、重启恢复与关闭后的后台进程状态。
