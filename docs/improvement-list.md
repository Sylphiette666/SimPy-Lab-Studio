# 用户按编号选择的改进名单

以下编号对应原对话中的 20 项名单，后续保持不变。仅实现用户当次指定的项目。已完成状态指滚动测试分支，不代表已进入正式 Release。

1. **运行助手增强**：对话搜索、复制、导出，以及表格、公式和代码的清晰显示。已完成，见 [对话工具](conversation-tools.md)。
2. **AI 修改预览**：应用前展示参数修改前后的对比、修改理由及预计影响。
3. **AI 请求控制**：支持取消请求、超时重试和明确的处理进度。
4. **API 密钥安全保存**：支持用户选择本机加密保存，减少重复填写。已完成，见 [密钥保存](credential-storage.md)。
5. **异常恢复**：软件意外关闭后恢复对话、未保存的模型编辑和运行状态。
6. **模型可视化编辑**：通过拖拽添加设备、容器和连接线。已完成，见 [图形建模](visual-model-editor.md)。
7. **复杂生产线支持**：增加并行设备、分支、汇合、返工和多产品路线。
8. **设备与容器模板库**：保存常用参数组合，支持复制和批量编辑。
9. **模型数据导入**：支持通过 Excel、CSV 或 JSON 批量导入参数。
10. **参数检查与解释**：标注单位、合理范围、关联约束及错误位置。
11. **仿真状态续接**：支持保存运行检查点，并明确模型调整后重跑或续接的规则。
12. **可视化细节增强**：支持画布缩放、平移、设备聚焦及物料流动轨迹。
13. **瓶颈分析**：展示设备利用率、阻塞时间、缺料时间和缓冲区占用热力图。
14. **指标趋势图**：展示产出率、在制品和能耗随仿真时间的变化。
15. **批量方案实验**：支持参数扫描、敏感性分析和实验任务队列。
16. **多目标优化**：同时考虑产能、能耗、在制品和改造成本。
17. **评估可信度增强**：增加统计显著性分析、重复次数建议和实际生产数据校准。
18. **报告导出增强**：支持 PDF、Excel，以及自定义图表和报告模板。
19. **发布体验完善**：增加数字签名、软件内更新检查和更新日志。
20. **易用性与性能优化**：改善高分屏适配、键盘操作、大模型场景流畅度和长时间运行稳定性。
