# 用户按编号选择的改进名单

以下编号对应原对话中的 20 项名单，后续保持不变。仅实现用户当次指定的项目。第 1、4、6 项已随 v1.2.0 正式发布；其余项目仍按用户指定逐项实现。

1. **运行助手增强**：对话搜索、复制、导出，以及表格、公式和代码的清晰显示。已完成，见 [对话工具](conversation-tools.md)。
2. **AI 修改预览**：应用前展示参数修改前后的对比、修改理由及预计影响。已在滚动测试版实现显式确认，见 [可靠性更新](reliability-update.md)。
3. **AI 请求控制**：支持取消请求、超时重试和明确的处理进度。已在滚动测试版实现取消、阶段/等待时间、超时及手动重试；远端调用可能继续完成。
4. **API 密钥安全保存**：支持用户选择本机加密保存，减少重复填写。已完成，见 [密钥保存](credential-storage.md)。
5. **异常恢复**：已将参数、图形、撤销历史和输入草稿持久化到实验目录，支持端口变化、缓存清理后的恢复与草稿修订冲突保护。中断仿真仍需重跑。见 [本轮更新](productivity-update.md)。
6. **模型可视化编辑**：通过拖拽添加设备、容器和连接线。已完成，见 [图形建模](visual-model-editor.md)。
7. **复杂生产线支持**：增加并行设备、分支、汇合、返工和多产品路线。
8. **设备与容器模板库**：保存常用参数组合，支持复制和批量编辑。
9. **模型数据导入**：已支持 CSV / 单工作表 XLSX 的字段映射、逐行错误、修改预览与显式导入，保留 JSON 导入。
10. **参数检查与解释**：已补充单位、范围说明、关联约束检查和错误字段定位。
11. **仿真状态续接**：支持保存运行检查点，并明确模型调整后重跑或续接的规则。
12. **可视化细节增强**：支持画布缩放、平移、设备聚焦及物料流动轨迹。
13. **瓶颈分析**：已提供完整重复实验的设备状态时间分解、利用率线索及缓冲占用热力图。
14. **指标趋势图**：展示产出率、在制品和能耗随仿真时间的变化。
15. **批量方案实验**：已实现最多 3 参数、16 组合的扫描、持久任务队列、取消、结果排序和 CSV 导出，显式采用候选方案。
16. **多目标优化**：同时考虑产能、能耗、在制品和改造成本。
17. **评估可信度增强**：已增加 t 区间、同种子配对检验和目标精度的重复次数建议；通过批量扫描与实际 KPI 相对误差做有限参数校准。假设、适用范围与限制见本轮更新。
18. **报告导出增强**：支持 PDF、Excel，以及自定义图表和报告模板。
19. **发布体验完善**：增加数字签名、软件内更新检查和更新日志。
20. **易用性与性能优化**：改善高分屏适配、键盘操作、大模型场景流畅度和长时间运行稳定性。

21. **API 连接测试**：已实现对当前编辑配置的短请求测试、延迟/用量展示及分类错误，不自动保存配置。
22. **模型选择辅助**：读取服务可用模型列表，同时保留手动输入。未选择实施。
23. **AI 评估解读**：基于实际仿真结果解释方案改善与权衡，区分计算结果和 AI 推测。未选择实施。
24. **实验管理与备份**：已实现搜索、重命名、标签、归档、手动/每日备份、实验 ZIP 与备份恢复；恢复创建新实验。
25. **仓库与文档一致性**：当前开发和推送统一到 R-0xy/SimPy-Kpi-Lab 的 main，当前源码包与历史安装包清晰区分。
