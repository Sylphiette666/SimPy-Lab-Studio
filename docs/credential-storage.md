# API 密钥的本机加密保存

此功能属于基于 v1.1.0 的滚动测试版，不改变已发布的 v1.1.0 安装包。

## 使用

1. 打开“模型接入”，选择配置，填写 API 地址、模型和密钥。
2. 勾选“在本机加密保存密钥”，点击“保存并启用”。也可以将本次运行已配置的密钥转为加密保存，输入框留空即可。
3. 退出并重新打开软件后，同一 Windows 用户下自动恢复可读取的密钥。输入框始终不会显示已保存的明文。

新建或复制配置默认不勾选保存，复制配置不复制密钥。切换配置保留每个连接独立的保存设置。

- **取消勾选并保存**：删除磁盘中的密钥副本，本次运行仍可使用内存中的密钥；下次启动需要重新填写。
- **勾选“移除此配置密钥”并保存**：删除磁盘副本及当前配置的内存密钥。已经发出的请求保留发送时的快照，不会被中途改写。
- **更改 API 地址**：没有明确填写新密钥时清除原服务的密钥和磁盘副本；重新输入的新密钥按保存选项处理。
- **密钥无法读取**：界面提示重新填写或移除。原密文保留，普通元数据编辑不会覆盖它；手动仿真和已有实验仍可使用。
- **关闭窗口而未保存**：不改变密钥保存设置。

环境变量提供的默认连接密钥仍只在内存中使用，除非用户明确选择加密保存。删除软件中的密钥不会修改操作系统环境变量。

切回第一版或已发布的 v1.1.0 前，请先在测试版取消所有配置的加密保存并保存。这会恢复旧版可识别的连接列表格式；旧版不支持新增的密文字段。不启用加密保存时，文件保持原有格式。

## 保存范围

使用 Windows DPAPI 的当前用户范围，不使用所有本机用户均可解密的机器范围，不在程序中内置加密口令。密文同时绑定配置 ID 和 API 地址，不能通过复制密文字段把旧服务的凭据用于另一份配置。

配置与密文以一个 JSON 文件原子写入：桌面版位于 `%LOCALAPPDATA%\SimPy Lab Studio\experiments\ai_profiles.json`。加密或写入失败时，原配置和原密钥继续有效。非 Windows 系统不提供新的持久保存，也不回退为明文保存。

同一 Windows 用户登录上下文内的其他程序仍可能调用 DPAPI；此功能不提供对已控制当前账户的程序的隔离。更换电脑、Windows 账户或账户恢复环境后，可能需要重新填写密钥。原理与边界见 [微软 CryptProtectData 文档](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata) 和 [CryptUnprotectData 文档](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptunprotectdata)。

密钥明文不落盘；密文不会进入 API 返回、实验会话、HTML 报告或实验导出 ZIP。分享 EXE、安装程序或源码包不会包含用户密钥。复制整个本机数据目录时会包含已保存密文。

## 验证

`tests/test_studio_credentials.py` 验证 Windows DPAPI 跨进程恢复、服务与配置绑定、取消保存、清除、更换地址、失败回滚及导出隔离。`tools/check_credentials_browser.cjs` 在隔离测试服务中检查保存选项、状态、草稿和窗口布局；不调用真实模型。EXE 的 `--self-test` 额外验证后台服务重启后能恢复测试密钥及删除密文。
