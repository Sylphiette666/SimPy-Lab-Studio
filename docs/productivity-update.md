## 参数导入边界

支持 UTF-8（含 BOM）和 GB18030 CSV，以及单工作表 XLSX；不执行 Excel 公式、宏或外部链接。公式单元格须先粘贴为数值。限 1 MB、500 条数据行、40 列；不读取旧 .xls。

对象类型为“设备”或“容器”，序号从 1 开始，对应当前产线顺序；可映射自定义列名。可用率输入百分数（90 表示 90%），空单元格保留原参数。模板导出对公式样式文本作转义。导入仅更新现有对象参数，不新增拓扑；纸面案例约束仍生效。行解析或整模校验失败不会部分应用。

## 草稿、备份与恢复

草稿按实验写入 `experiments/<实验 ID>/drafts.json`，最后打开的实验及备份选项在 `experiments/workspace.json`。浏览器存储仅作为即时缓存及旧草稿迁移来源。成功同步后，清理浏览器缓存或改变本机服务端口不会丢失文件草稿。同步失败会提示并重试；窗口在最后一次写入完成之前被强制结束，仍可能丢失尚未同步的输入。

每类草稿带修订号；另一窗口已更新时不覆盖其内容，本窗口冲突内容保留并可在实验管理中导出。草稿尚未保存为模型版本时，仍需“应用修改并预览”才会生效。

自动备份默认关闭。开启后先生成一份备份；软件运行期间每分钟检查一次，距上次成功备份满 24 小时再备份，保留最近 7 份。不是操作系统定时任务，软件关闭期间不执行。备份位于 `experiments/backups`，包含实验、版本、对话、已完成结果、草稿和批量任务；排除 API 连接目录、明文密钥、加密密钥和程序文件。

恢复支持新的完整备份 ZIP 和已有“导出实验”的 ZIP。先显示待恢复实验清单，确认后使用新实验 ID 写入，不覆盖原实验。已完成运行和批量结果可继续查看，未完成的任务标为中断。ZIP 不解压任意路径，只导入验证通过的已知 JSON 内容；上传限 25 MB，展开限 100 MB、100 个实验。

## 批量实验与校准

所有组合先整体校验，再进入单工作线程顺序队列，最多两个在途批量任务。每组使用相同实验设置和按重复编号派生的随机种子；整批事件量上限为 800 万。取消在当前一次重复完成后生效；已完成组合保留。任务和进度写入本机文件，重启不自动重跑中断任务。

结果排序不等于全局最优。选择“采用此方案”后通过原有版本校验和预览流程生效；基准版本已变化时禁止覆盖。实测校准指标必须是同统计口径的正数，评分为所填指标相对误差的均方根。它是有限参数网格内的匹配工具，不是自动识别所有参数；应用前应使用独立生产数据验证，避免用同一批数据拟合并宣称验证通过。

## 统计口径

现有汇总报告的正态近似结果保留，新增诊断从完整重复实验原始记录计算 Student t 区间。配对检验按重复编号及随机种子匹配，要求时长、预热、基础种子和置信水平一致；缺失能耗等指标只使用有效配对。

方法依据：[NIST 均值置信区间](https://itl.nist.gov/div898/handbook/eda/section3/eda352.htm)、[NIST 配对观测分析](https://www.itl.nist.gov/div898/handbook/prc/section3/prc311.htm)。假设独立重复及重复均值/差值近似正态；多指标检验尚未校正，仅供探索。单次结果不计算区间，零观测方差不视为确定性证据。建议重复次数以当前样本方差固定估计；超过桌面端 50 次上限时会提示调整实验设计，不会自动消耗计算资源。

设备状态和缓冲占用来自事件积分后的完整重复实验，排除预热；不使用采样动画帧推断时间比例。高利用率只是瓶颈线索，应结合缺料、阻塞及参数实验验证。
