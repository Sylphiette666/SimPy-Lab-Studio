# 1.0.0 发行版验证

验证日期：2026-09-14。实测系统：Windows 11 家庭版中文版 x64，系统版本 10.0.26200；WebView2 Runtime 152.0.4191.66。Windows 10 x64 为目标支持平台，本次未在 Windows 10 真机复测。

- 完整 Python 测试：232 项通过；仅出现上游 Starlette/AnyIO 的弃用提示。
- 代码检查：`ruff check src tests` 与桌面构建、窗口检查脚本通过。
- 浏览器回归：编辑模型、播放/暂停/拖动、统计评估、版本恢复、模型导入、实验导出与移动布局通过。
- AI 连接配置：新建两套连接、保存并启用、随时切换、保留回放位置、刷新后保留配置、历史模型来源通过。
- 后端连接隔离：每套密钥独立；配置文件、响应和导出不含密钥；正在执行的请求在切换或编辑配置后继续使用原配置快照。
- 最终 EXE 自检：以冻结程序运行，内置 HTML/CSS/JS/图标可加载，后台服务启动，实际 SimPy 预览成功，退出后子进程停止。
- 独立窗口：实测 Windows Forms + WebView2 原生窗口，可显示中文界面与菜单；没有启动外部浏览器。
- 原生文件保存：通过 Windows 保存对话框导出 ZIP，压缩包校验通过，包含会话、各版本、运行结果、CSV 与 HTML 报告。
- 重启恢复：再次启动最终 EXE 后恢复模型参数、模型连接列表及已完成统计结果；重复双击激活已有窗口，不新增后台服务。
- 退出清理：关闭主窗口后，桌面程序及其后台子进程退出，运行状态记录变为停止。

LLM 请求逻辑使用注入测试客户端与隔离测试服务验证，没有调用付费模型。真实服务是否接受用户填写的 API Key、模型和接口格式，由用户账户与服务能力决定。

验证中的短时实验是测试数据，不随软件发行。用户首次启动使用默认案例一模型。构建工具为 PyInstaller 6.22.3、pywebview 6.2.1、Python 3.13 x64；EXE 采用 Windows GUI 子系统和内嵌 ICO 图标。
