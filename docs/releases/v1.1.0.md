# SimPy Lab Studio v1.1.0

由测试分支 `frontend/simulation-workspace` 合并至 `main` 的正式版。第一版 v1.0.0 发布记录与资产继续保留。

## 相比 v1.0.0

- 仿真画面占据主要区域，支持全屏工作区、暂停、变速与时间轴回放，右侧展示动态指标。
- 运行前可编辑模型、添加或移除串联设备及配套缓冲容器，并保留方案版本；自定义实验最多 12 台设备。
- 运行助手支持放大查看对话，保留输入草稿和阅读位置，展开后仍可切换 AI 模型和发送指令。
- 模型、结果评估及放大的助手窗口支持点击外侧关闭，也保留关闭按钮与 Esc。
- 完整重复评估、历史方案比较、独立 HTML 报告与实验 ZIP 导出均保留。
- 修复 AI 请求输出额度不足和未完成响应的处理，明确显示截断、拒绝、空正文等错误；DeepSeek 官方接口的参数调整采用非思考模式。失败不会应用不完整参数。

## 下载和更新

在 [v1.1.0 Release](https://github.com/Sylphiette666/SimPy-Lab-Studio/releases/tag/v1.1.0) 下载 `SimPy-Lab-Studio-Setup-1.1.0.exe`，可以直接分享给其他人。便携版和带来源清单的源码 ZIP 也在同页提供，`SHA256SUMS.txt` 用于校验下载文件。

支持 Windows 10/11 x64，带应用图标、中文安装向导、快捷方式和卸载入口，无需 Python 或 CMD。后台服务随独立窗口自动启停。安装前请退出正在运行的 Studio；已有安装可直接覆盖更新，实验数据保留。缺少 WebView2 时安装程序需联网获取微软组件。

安装包不包含个人 API 密钥或实验记录。API 密钥仍只保存在服务进程内，重启后需重新填写。程序和安装包尚未进行商业代码签名。

## 结果解释与边界

本次没有修改 SimPy 仿真引擎、指标计算或物理模型约束。动画为二维采样状态回放，暂停不会冻结已在后台计算的仿真；AI 调整后从初始状态运行新方案。是否改善以相同条件下的完整重复实验为准。

发布验证包括程序测试、打包资源检查、真实短时仿真、安装与覆盖安装、快捷方式与版本登记、卸载及用户数据保留。验证使用模拟 AI 响应，不调用用户付费 API。本机已有 WebView2；没有在缺失该组件的全新 Windows 系统上实测自动安装流程。
