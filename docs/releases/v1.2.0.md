# SimPy Lab Studio v1.2.0

本版将最新测试分支合并至 `main`，提供图形建模、运行助手对话工具、本机密钥加密保存和历史方案完整评估详情。v1.0.0、v1.1.0 的发布记录和文件保持不变，后续开发继续使用原滚动测试分支。

## 相比 v1.1.0

- **图形建模（第 6 项）**：拖入设备与缓冲容器，通过端口建立连接，选中节点编辑参数；支持移动、删除、撤销/重做和自动排列。可应用到输入模型或直接运行预览，按连线确定加工顺序，并沿用原有串联模型与后端校验。
- **运行助手增强（第 1 项）**：搜索对话并跳转匹配、复制单条回复或代码、导出 Markdown / TXT / JSON 全部对话。表格、代码和 LaTeX 公式可离线排版；侧栏与放大窗口保留草稿和阅读位置。
- **可选密钥保存（第 4 项）**：在“模型接入”勾选后，使用 Windows 当前用户 DPAPI 加密保存，重启后恢复。默认仍仅本次运行使用；可取消保存或清除密钥，密钥与密文不返回界面、不加入实验导出。
- **历史方案详情**：先前版本也可在完整评估窗口查看对应指标、置信区间、方案说明、修改记录、AI 来源与模型，并导出对应报告。支持切换查看版本；查看历史不会恢复模型或暂停回放。

原有可视化仿真、暂停/变速/时间轴、AI 接入切换与自然语言调整、完整重复评估、方案对比和报告导出均保留。

## 下载与升级

在 [v1.2.0 Release](https://github.com/Sylphiette666/SimPy-Lab-Studio/releases/tag/v1.2.0) 下载 **`SimPy-Lab-Studio-Setup-1.2.0.exe`**，可直接分享给他人。同页提供 Windows x64 便携 ZIP、完整源码 ZIP 和 SHA-256 校验文件。

支持 Windows 10/11 x64。中文安装向导包含图标、桌面/开始菜单快捷方式与卸载入口；无需 Python、CMD 或手动启动服务。安装前先退出软件，运行新安装包即可覆盖升级，实验与模型连接列表保留。已有 WebView2 时可离线安装；缺少该组件时，安装程序使用微软官方引导程序联网安装。

安装包不包含个人实验或 API 密钥。程序与安装包尚未进行商业代码签名。若要降级至 v1.0.0 或 v1.1.0，请先在新版取消所有配置的加密保存并保存，恢复旧版可读格式，详见 [密钥保存说明](../credential-storage.md)。

## 验证与适用范围

发布验证涵盖单元与集成测试、前端交互、打包资源与源码一致性、桌面程序自检、真实短时仿真、全新安装、v1.1.0 覆盖升级、版本登记、快捷方式、卸载和原有用户数据保留。测试使用独立数据及注入的 AI 响应，不调用用户付费 API。

本机验证环境为 Windows 11 x64，已有 WebView2；未在缺少 WebView2 的全新 Windows 系统或 Windows 10 上完成实机验证。

本版没有修改 SimPy 仿真引擎、指标计算或物理模型约束。图形编辑支持串联路线，最多 12 台设备，不支持并行、分支或返工。动画是二维采样状态回放；暂停不冻结后台计算，AI 调整后从初始状态运行新模型。改进效果应以相同条件下的完整重复实验为准。
