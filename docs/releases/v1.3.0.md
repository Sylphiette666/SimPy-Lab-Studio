# SimPy Lab Studio v1.3.0

本次完成高优先级清单 5、9、10、13、15、17、21、24、25 项。主界面点击 **实验工具** 使用新增功能。

- 草稿保存在应用数据目录，恢复表单、图形编辑、未发送提示词和回放位置，不受端口或浏览器缓存影响。
- CSV / Excel 参数导入、字段映射、行号错误和修改预览；参数单位、关联检查与错误定位。
- 设备状态时长分解、缓冲占用热力图和瓶颈排查线索。
- 参数组合扫描、顺序队列、取消待运行项、指标排序和候选方案采用。
- 条件一致的精确配对符号检验、重复次数建议、实测数据参照和候选校准比较。
- API 连接测试，分别提示密钥、地址、模型、限额和超时问题。
- 实验搜索、名称、标签、归档、完整实验包恢复、定期备份与保留数量。
- 当前仓库、源码包、桌面程序、安装程序及下载文档统一为 v1.3.0。

保留原有图形建模、助手对话、加密密钥保存、历史详情、SimPy 仿真与 KPI 算法。草稿恢复不等于未完成仿真的检查点续算；瓶颈与校准功能提供分析依据，不保证最优方案。具体口径与限制见 [使用说明](../priority-upgrades.md)。

## 下载和升级

在 [v1.3.0 Release](https://github.com/Sylphiette666/SimPy-Lab-Studio/releases/tag/v1.3.0) 下载 **SimPy-Lab-Studio-Setup-1.3.0.exe** 分享和安装。同页提供单文件 EXE、Windows x64 便携 ZIP、源码 ZIP 与 SHA-256。

Windows 10/11 x64，需要 WebView2。安装程序可使用微软官方引导程序补装；已有运行库时可离线安装。退出旧版后运行安装程序覆盖升级，保留本机实验和配置。此开源发行版的应用与安装程序未作商业代码签名。

修改前 main 保存于 [archive/v1.2.0-before-priority-upgrades](https://github.com/Sylphiette666/SimPy-Lab-Studio/tree/archive/v1.2.0-before-priority-upgrades)。以往 Release 文件保持原样；后续开发继续使用 `frontend/simulation-workspace`。
