SimPy Lab Studio 1.0.0 — 安装与使用说明

这是用于生产线建模、仿真回放和 AI 辅助调整的 Windows 桌面软件。

安装条件
• Windows 10/11，64 位 Intel 或 AMD 电脑。
• 无需安装 Python，无需使用命令行，也无需手动启动本地服务。
• 安装程序会检测 Microsoft WebView2 Runtime；缺失时使用微软官方程序联网安装。
• 电脑已有 WebView2 时，可以离线完成安装。缺失时请保持网络连接。

安装方式
运行安装程序，选择安装位置和是否创建桌面快捷方式，点击安装。
默认安装到当前用户的本地 Programs 目录，通常无需管理员权限。
安装完成后，可从桌面或开始菜单打开 SimPy Lab Studio。

基本使用
1. 编辑左侧的设备、缓冲区和班次参数，应用修改并运行预览。
2. 播放、暂停、变速或拖动时间轴，观察生产线状态。
3. 在“模型接入”填写自己的 API 地址、AI 模型名称和 API Key，保存并启用。
4. 在助手面板切换模型、输入调整目标，通过校验后生成新版本并重新仿真。
5. 运行统计评估比较各方案，再导出实验包。

数据保存
实验与模型连接列表保存在 %LOCALAPPDATA%\SimPy Lab Studio。
API Key 只在内存中保存，退出软件后需要重新填写。
软件关闭时会停止自己的后台服务；尚未完成的实验下次需要重新运行。

升级和卸载
先关闭软件，再运行新版本安装程序，可覆盖更新程序文件。
在 Windows 设置的“已安装的应用”中找到 SimPy Lab Studio，即可卸载。
卸载会移除程序和快捷方式，保留实验数据，也不卸载共享的 WebView2 Runtime。

结果说明
动画展示 SimPy 的采样状态，最终效果应通过完整重复实验验证。
当前是二维串联制造线仿真，不包含写实三维工厂，工程使用需实际数据校准。
